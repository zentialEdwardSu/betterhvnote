# 工具栏、编辑与备份扩展

## 功能入口

- 橡皮按钮直接切换整笔／局部擦除，笔尖工具不变。笔尾在非空选区边框内落下会一次删除全部所选对象；整次手势随后被消费，撤销一次即可恢复。
- 仅包含空白页的笔记本隐藏 PDF 导航；切换笔记本时也会关闭无效的导航浮层。
- 全本至少两张夹页时，页面面板按普通页面／全部夹页分列；顶部、底部停靠时分排。两列分别滚动，共用书签筛选。
- 添加摘抄先选择夹页缩略图或新建夹页，再点击页面放置。目标可以是本笔记任意夹页，每条摘抄保留自己的 PDF 来源。
- 应用设置 → 按键绑定：左侧选择 K1–K8，右侧搜索命令、选择参数并绑定。保留编辑、页面管理、插入三个场景和实体键识别。
- 图片／文字插入来源中可选择剪贴板；也可直接绑定“从剪贴板插入图片／文字”。图片 URI 被复制为本地资产，文字保留换行。
- 应用设置 → 备份与恢复：导出完整 ZIP、导入整体恢复、回滚至最近一次恢复前副本。恢复前展示时间与笔记本数量，确认后整体替换。

## 命令与工具栏对象扩展

工具栏项现在由 `com.betterhv.note.toolbar` 中的工具对象描述：`ToolbarTool` 按主副作用分为画板、悬浮窗、全屏页面和即时文档操作四个密封分支；`ToolbarCatalog` 显式持有 14 个工具、共享动作、命令和窗口元数据，不使用反射。每个工具同时提供主命令、双击/Side1/2/3 引用、可用性/可见性/选中态和展示信息。`SharedToolbarActions` 提供 `pen.settings`、页面和建本等跨工具命令。

`CommandRegistry` 只合并 `ToolbarCatalog.commands` 与非工具栏命令；`ToolbarCommandRouter` 把工具命令路由到 `ToolEffectSink`，由 `AppRoot` 解释为 `penView` 和界面状态变化。非工具栏命令仍由 `MainActivity` 的现有执行器处理。新增工具只需增加一个工具类和一条 `ToolbarCatalog.tools` 注册；它的主命令和手势命令会自动进入 K1–K8 绑定目录。不要恢复旧的 `ToolbarCommandItem` 表或按工具 ID 的 `when` 分支。

## 电子纸 UI 规范

工具栏、笔设置/插入/Menu/PDF 导航 flyout、页面管理、笔记本管理、导出管理、应用设置页（含 `HardwareBindingsPanel` 和备份/恢复维护页）使用 `com.betterhv.note.ui` 的 `EinkTheme`/`EinkTokens`/`Eink*` 组件：黑/白/灰 chrome、直角、1dp 外框、无阴影、44dp 触控区和统一字体层级。笔色色块与页面/笔记本缩略图是内容，可以保留真实颜色；不要为状态新增绿/红颜色，使用反色、图标、文字或双线边框。`EinkTheme` 只包裹这些明确的前台，不要套到应用根节点，避免改变 NoteLink、画布和模板/文档设置。

数据库语义版本为 v8，无新增表。`parentPdfPageId` 决定夹页归属，`PdfAnchor.sourcePageId` 决定摘抄来源；校验要求来源为 PDF 原页、目标为同一本笔记的夹页。

## 备份协议与恢复顺序

ZIP 首项是 `manifest.json`，记录格式版本、数据库版本、备份时间、笔记本数量，以及每个文件的相对路径、大小和 SHA-256。包含数据库、图片、原始 PDF、模板本地副本及清单、应用／画笔设置（含按键绑定）；不包含导出产物、缩略图、日志、临时导入文件和 NoteLink 配对凭据。

进入维护界面时暂停输入，等待资产导入和保存，关闭文档、导出及缩略图会话。SQLite checkpoint 必须成功后才复制数据库。解包只允许规定路径，校验大小与哈希，在暂存数据库中迁移旧版本并检查完整性、外键与资源引用。

恢复前保存当前数据，写入持久化恢复记录，再替换文档、模板和设置。完成验证后清除记录；中断启动时，在打开编辑器之前恢复旧副本。最近一份恢复前副本留供手动回滚。恢复后清除可再生缓存并重新建立编辑会话；模板无需重新授权外部目录即可离线使用。

## 验证范围

自动化覆盖命令目录与旧绑定、工具对象目录/命令派生/效果计划、混合对象一次删除／撤销、选区命中、模态阻断、八键原始事件与重复过滤、剪贴板文字／图片 URI、无 PDF 导航隐藏、维护界面进出、四边停靠双列布局、书签筛选与参数绑定。UI 验证额外覆盖工具栏、flyout、页面管理、笔记本/导出管理和对话框的截图，以及 `EinkTokens` 的黑白灰、尺寸和圆角约束。

备份真机测试使用隔离目录，覆盖图片、模板、双 PDF 原页、跨页摘抄的恢复与回滚；还覆盖 v7→v8、截断 ZIP、更新版本拒绝、缺失资产以及持久化恢复记录触发的启动回滚。

仍需人工使用真实笔尾和八个实体键操作，核对电子纸残影／刷新观感，以及厂商系统截图提供器的实际剪贴板授权。自动注入 Android 事件、测试图片提供器和截图布局检查不能替代这些硬件验收。存储空间不足分支有预检，未在用户设备上实际耗尽存储；恢复中断通过持久化记录与不完整数据库模拟，未进行断电测试。
